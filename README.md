# 🤖 Чат MAX (Тестовое задание)

Реализация пользовательского интерфейса чата для мессенджера MAX на React (Vite).

## 📋 Требования

*   **Стек:** React, Vite.
*   **Архитектура:** Разделение логики и UI (`src/services`, `src/components`).
*   **API:** Mock-реализация (JSON-данные) для демонстрации работы UI, состояний и асинхронности.
*   **Дизайн:** Прототип web.max.ru (пузыри сообщений, выравнивание, время).

> ⚠️ **Важно про GREEN-API:**  
> Прямое подключение GREEN-API из браузера невозможно из-за ограничений CORS и требований безопасности (токены нельзя хранить на клиенте). В рамках тестового задания реализована **Mock-логика** (`src/services/api.js`), которая эмулирует поведение методов `SendMessage` и `ReceiveNotification`. Это демонстрирует понимание архитектуры «Frontend + Backend Proxy», необходимой для продакшена.

## 🚀 Как запустить локально

1.  **Установи зависимости:**
    ```bash
    npm install
    ```
2.  **Запусти сервер разработки:**
    ```bash
    npm run dev
    ```
3.  **Открой в браузере:**
    Ссылка появится в терминале (обычно `http://localhost:5173`).

## 🗂 Структура проекта

*   `src/App.jsx` — главный компонент, управление состоянием (сообщения, загрузка, ошибки), логика отправки.
*   `src/services/api.js` — слой API. Содержит функции `getMessages` и `sendMessage` с имитацией задержек сети (`setTimeout`) и единой форматизацией времени.
*   `src/App.css` — стилизация чата (Flexbox, адаптивные пузыри, выравнивание времени).
*   `public/` — статические файлы.

## ✨ Особенности реализации

*   **Единый формат времени:** Используется кастомная утилита для формата `ЧЧ:ММ`, чтобы избежать различий локалей.
*   **Выравнивание:** Сообщения пользователя — справа (зелёный фон), системные — слева (серый фон). Время прижато к соответствующему краю пузыря.
*   **Асинхронность:** Обработка состояний `isLoading` и `error` при загрузке и отправке.
*   **UX:** Блокировка кнопки и поля ввода во время загрузки.

## 📝 Для HR (инструкция по проверке)

1.  Открой страницу. Увидишь два системных сообщения-заглушки.
2.  Введи текст в поле ввода и нажми «Отправить».
3.  Проверь:
    *   Появилось ли сообщение справа с корректным временем.
    *   Работает ли блокировка кнопки при «отправке».
    *   Корректно ли отображаются ошибки (если вызвать искусственно).
4.  Посмотри код в `src/services/api.js`: там есть комментарии, почему используется Mock, а не прямой запрос к GREEN-API.
